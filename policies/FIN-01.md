# FIN-01: Unauthorized and unrecognized transactions
Track: fintech

Steps, in order:
1. Compelling evidence (FIN-03): deny.
2. Customer does not recognize the charge, but has 2+ earlier undisputed transactions with the same merchant: deny and explain the billing descriptor.
3. The transaction has neither IP address nor device ID, and there is no compelling evidence: request more information.
4. Otherwise: approve a refund of the transaction amount.
